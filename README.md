## ✨ Özellikler
* 📑 **Çoklu Liste Yönetimi:** Market, Ev, İş gibi farklı ihtiyaçlar için ayrı listeler.
* 📈 **İlerleme Takibi:** Tamamlanan ürünleri görsel ilerleme çubuğuyla izleyin.
* 🚨 **Acil Durum Etiketi:** Kritik ürünleri kırmızı vurguyla işaretleyin.
* ↔️ **Kaydırarak Silme:** Listeleri tek bir hareketle pratik şekilde yönetin.
* 💰 **Tahmini Fiyatlandırma:** Bütçenizi önceden planlamak için fiyat ekleyin.
* 🔐 **Çevrimdışı Kullanım:** Hive veritabanı sayesinde internet gerekmez.
* 🚀 **Splash Screen:** Şık ve profesyonel açılış animasyonu.
